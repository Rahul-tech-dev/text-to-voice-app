
# Text-to-Speech App

A responsive Text-to-Speech application built using HTML, CSS, and JavaScript.

## Features
- Convert written text into speech.
- Dynamically load available voices.
- Select different voices.
- Adjust speech rate and pitch.
- Start and stop speech.
- Modern and responsive user interface.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Web Speech API

## What I Learned
- DOM manipulation
- Event listeners
- JavaScript functions
- Working with browser APIs
- Handling dynamic user interactions

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `main.html` in your browser.
